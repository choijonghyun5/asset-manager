# 자산 관리 앱 (5단계 · PWA)

## 폴더 구조
```
asset-tracker/
├─ index.html          앱 진입점
├─ manifest.json        PWA 매니페스트 (홈 화면 추가용)
├─ service-worker.js     오프라인 캐싱
├─ css/
│  └─ style.css         전체 스타일
├─ js/
│  ├─ data.js            상수/포맷 유틸 (자산 종류, 날짜, 금액 콤마 포맷, 그레이 팔레트 등)
│  ├─ storage.js         localStorage 저장/불러오기
│  ├─ exchange.js        USD/KRW 환율 조회 (실시간 → 캐시 → 수동 폴백)
│  ├─ drive.js            Google Drive 백업/복원 (5단계, Google Identity Services 사용)
│  ├─ charts.js          도넛차트 / 라인차트 SVG 생성
│  └─ app.js             상태관리 + 화면 렌더링 + 이벤트 처리
└─ icons/
   ├─ icon-192.png
   └─ icon-512.png
```

## 로컬에서 실행하는 방법
PWA는 `service-worker.js` 때문에 파일을 더블클릭해서 여는 방식(`file://`)으로는
정상 동작하지 않습니다. 반드시 로컬 서버로 실행해주세요.

터미널에서 폴더로 이동한 뒤:

```bash
python3 -m http.server 8080
```

그 다음 브라우저에서 `http://localhost:8080` 접속.

모바일에서 확인하려면 같은 Wi‑Fi에 연결한 뒤 PC의 IP 주소로 접속하거나,
Vercel / Netlify / GitHub Pages 같은 정적 호스팅에 이 폴더를 그대로 배포하면 됩니다.
(https 환경이어야 실제 폰에서 "홈 화면에 추가"가 정상 동작합니다.)

## 디자인 리프레시

`css/style.css`를 참고 앱("STUDY.")의 무채색 디자인 시스템에 맞춰 다시 작성했습니다.
Pretendard 폰트, 필(pill) 모양 버튼, 베벨·글로우 그림자를 가진 카드, 바텀시트형
모달, 블러 처리된 하단 탭바 등으로 톤을 통일했고, 숫자 표시에는 모노스페이스
폰트(`--font-mono`)를 사용합니다. 기존 HTML 구조와 클래스명(`js/app.js`가 생성하는
마크업)은 그대로 두고 CSS 변수/컴포넌트 스타일만 교체했으므로 기능 로직에는
변경이 없습니다. 시스템이 다크 모드이면 `prefers-color-scheme: dark` 미디어
쿼리로 자동으로 어두운 톤으로 전환됩니다(별도의 다크모드 토글 버튼은 없습니다).

## 지금까지 구현된 범위 (1~3단계)

**1~2단계**
- 자산(Asset) / 자산 기록(AssetRecord) 데이터 구조, localStorage 저장
- 탭 골격: 홈 / 자산 / 추가 / 분석 / 설정
- 자산 추가·목록·상세(기록 추가/수정/삭제) CRUD
- 무채색 미니멀 디자인 시스템, 모바일 입력 최적화(확대 방지, numeric 키패드)

**3단계 (이번 단계)**
- 홈 화면: 현재 총자산, 목표 대비 진행률, 이번 달 증감액/증감률
- USD/KRW 환율 실시간 조회 (`js/exchange.js`) — 조회 실패 시 마지막 캐시,
  캐시도 없으면 설정의 수동 환율로 자동 폴백. 오프라인에서도 앱이 죽지 않음
- 달러 자산 입력 시 실시간 환율 기반 원화 환산 미리보기
- 자산 비중 도넛차트 (무채색 그라데이션, `js/charts.js`)
- 목표 자산 비중 설정 (합계 100% 검증) + 현재 vs 목표 비중 비교 화면
- 자산 변화 라인차트 (전체/개별 자산, 기간 필터: 1개월/3개월/6개월/1년/전체)
- 통계: 최대 증가·감소 월, 평균 월 증가액, 최고·최저 총자산,
  기준값을 직접 설정할 수 있는 누적 성장률

환율 API는 별도 키가 필요 없는 `open.er-api.com`을 사용합니다. 다른 환율
소스로 바꾸고 싶다면 `js/exchange.js`의 `FX_API_URL`만 수정하면 됩니다.

**4단계 (목표 달성일 예측)**
- 분석 탭에 "목표" 서브탭 추가: 현재 자산·목표 자산 요약, 매월 저축(예정) 금액 입력,
  월 성장률 산출 방식 선택(자동 계산 / 직접 입력 / 0% 기준)
- 자동 계산 모드는 지금까지의 월별 총자산 데이터에서 평균 월 성장률을 구해 사용하고,
  데이터가 부족하면(성장률을 계산할 구간이 2개월 미만) 0% 기준으로 자동 대체하면서
  안내 문구를 보여줌
- 매달 "잔액 × (1+월성장률) + 월저축액"을 반복 계산하는 복리 시뮬레이션으로
  예상 목표 달성 연월, 남은 기간, 1년 후 예상 자산을 계산
  (성장률·저축액 조건상 50년 내 도달이 불가능하면 그 사실을 안내)
- 결과 하단에 "미래를 보장하지 않는 예상값"이라는 안내 문구를 항상 표시

**5단계**
- Google Drive 자동/수동 백업 + 백업 시점 선택 복원 (`js/drive.js`, 설정 탭)
- 모든 금액 입력창(자산 추가/기록 추가/목표 자산/성장률 기준값/매월 저축액)에
  천단위 콤마 자동 표시 (`js/data.js`의 `formatAmountInputValue` / `parseAmountInputValue`)

> 목표 달성일 예측(4단계)이 이번 업데이트로 반영되었습니다.

**자산 탭 월별 표시 방식 변경**
- 이전에는 자산 탭에서 특정 월을 조회하면 "그 시점까지의 마지막 기록값"이 이월되어 보였습니다
  (예: 10월에 500원 입력 후 11월에 기록이 없어도 500원이 계속 표시됨).
- 이제는 이월 없이, **그 달에 실제로 기록을 남긴 자산만** 그 달 창에 표시됩니다.
  10월에 현금·주식을 추가하고 11월에 주식만 기록했다면, 11월 창에는 주식만 보입니다.
- 같은 자산에 10월 500원 → 11월 1,000원처럼 기록하면, 11월 창에는 1,500원(합산)이 아니라
  1,000원(그 달에 입력한 값)이 표시됩니다. 각 월의 기록은 독립적으로 저장·표시됩니다.
- 단, 홈 화면의 "현재 총자산"과 분석 탭의 성장률/추이 그래프는 기존처럼 "가장 최근 기록값을
  다음 기록 전까지 유지"하는 방식을 그대로 사용합니다(그래야 자산을 매달 다시 입력하지 않아도
  총자산 추이가 끊기지 않습니다). 이번 변경은 **자산 탭의 월별 목록 화면에만** 적용됩니다.

## Google Drive 백업 설정 방법

이 앱은 **Google Identity Services(GIS)**의 "토큰 클라이언트" 방식을 사용합니다.
브라우저에서 바로 액세스 토큰만 발급받는 방식이라 **Client Secret이 전혀 필요 없고**,
프론트엔드 코드(`js/drive.js`)에는 Client ID만 들어 있습니다.

백업 파일은 사용자 Drive의 **숨겨진 앱 전용 폴더(appDataFolder)**에만 저장됩니다.
즉 사용자가 Drive에서 직접 볼 수 있는 일반 파일에는 전혀 접근하지 않습니다.
(액세스 토큰도 메모리에만 두고 저장하지 않으므로, 새로고침하면 다시 로그인해야 합니다.)

**연동 전 반드시 해야 할 설정 (안 하면 로그인 버튼을 눌러도 오류가 납니다):**

1. [Google Cloud Console](https://console.cloud.google.com/apis/credentials) 접속
2. 이 앱에서 사용 중인 OAuth 클라이언트 ID
   (`516093946835-qkq6q5tloe2f5p9dmucmafq07nrdbadp.apps.googleusercontent.com`)를 선택
3. **"승인된 자바스크립트 원본(Authorized JavaScript origins)"**에 이 앱을 실제로
   서비스하는 주소를 등록
   - 로컬 테스트: `http://localhost:8080` (포트는 실행한 포트에 맞게)
   - 배포 후: `https://your-domain.com` (실제 배포 도메인)
4. OAuth 동의 화면이 "테스트" 상태라면, 로그인할 Google 계정을 "테스트 사용자"로 추가
5. 저장 후 몇 분 내로 반영됩니다. 브라우저 캐시 때문에 안 되는 것처럼 보이면
   시크릿 창에서 다시 시도해보세요.

배포 도메인이 바뀔 때마다(예: Vercel 프리뷰 URL) 1번 단계를 반복해줘야 합니다.

### 백업/복원 동작 방식
- **자동 백업**: 설정 탭에서 켜면, 자산이 추가·수정·삭제될 때마다 4초 디바운스 후
  자동으로 백업합니다 (짧은 시간에 여러 번 수정해도 마지막 상태 1번만 업로드).
- **수동 백업**: "지금 백업" 버튼으로 즉시 백업.
- 백업할 때마다 타임스탬프가 붙은 새 파일이 생성되고, 오래된 백업은 최신 15개만
  남기고 자동 정리됩니다(중복 누적 방지).
- **복원**: "백업 불러오기"에서 시점을 선택하면, 확인 후 현재 기기의 데이터를
  해당 백업 내용으로 완전히 교체합니다.
